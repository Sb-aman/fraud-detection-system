# Fraud Detection System

A secure banking backend built with Node.js, Express.js, and MySQL. The project provides secure user authentication, money transfer functionality, transaction history, and rule-based fraud detection.

## Features

- User Registration & Login
- JWT Authentication
- Secure Password Hashing (bcrypt)
- Send Money API
- Transaction History
- Rule-Based Fraud Detection
- MySQL Database
- Input Validation
- Error Handling

## Tech Stack

- Node.js
- Express.js
- MySQL
- JWT
- bcrypt
- dotenv
